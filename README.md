# 📚 Object Study

조영호님의 **《오브젝트: 코드로 이해하는 객체지향 설계》**를 함께 읽고 학습하는 8주 스터디입니다.

## 🗓 스터디 일정

- 기간: 2026.11.09 이후 시작, 총 8주
- 시간: 주 1회, 매주 목요일 21:30~22:30
- 장소: 온라인 Google Meet

## 📖 커리큘럼

| 주차 | 학습 범위 |
|---|---|
| 1주차 | 1~2장 |
| 2주차 | 3~4장 |
| 3주차 | 5~6장 |
| 4주차 | 7~8장 |
| 5주차 | 9~10장 |
| 6주차 | 11~12장 |
| 7주차 | 13~14장 |
| 8주차 | 15장 + 부록 A, B, C |

## ✅ 진행 방식

### 1. 학습 및 정리
- 매주 지정된 범위를 읽습니다.
- 모든 스터디원은 학습 내용을 Markdown으로 정리하여 스터디 시작 전까지 GitHub에 업로드합니다.
- 정리 형식은 자유입니다.

### 2. 발표
- 스터디 당일 사다리타기로 발표자 2명을 선정합니다.
- 선정된 발표자는 각자 담당 범위를 발표합니다.

### 3. 자유 공유
- 이해되지 않았던 개념 및 질문
- 추가로 조사한 내용
- 실제 프로젝트 적용 및 리팩터링 사례
- 설계에 대한 고민이나 의견

## 📂 학습 기록

각 주차 폴더에 `이름.md` 형식으로 학습 내용을 업로드합니다.

예시: `week01/이승희.md`
